# Table Soccer / فوتبال دستی

Plato-style turn-based table soccer in React. Play vs bot — no backend.

## Features

- EN / FA with RTL
- 6 discs per side, drag-back flick
- Attack + defense formations, team & stadium select
- Pass to a teammate to keep your turn (unlimited chain)
- First to 3 goals

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173/`
